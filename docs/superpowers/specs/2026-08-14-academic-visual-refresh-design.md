# AIRTI 科研学术视觉刷新设计规格

**日期**：2026-08-14
**状态**：设计已确认，待实施
**应用范围**：GitHub README 项目图标与全人蛋白组反向钓靶流程示意图

## 1. 目标与边界

将 AIRTI 当前偏影视化、深色发光的三维视觉资产，替换为适合论文图形摘要、课题汇报和方法学说明的科研学术风格。新图应优先传达方法结构、阶段关系和证据边界，而不是营造商业宣传或科幻氛围。

本次只替换 `docs/assets/airti-icon.png`、`docs/assets/airti-workflow.png`，并同步修订 README 中与旧图风格不一致的图注措辞。不修改算法、容器、工作流参数、参考库或验证结论。

图片继续遵守无文字约束：不得包含文字、字母、数字、标签、图例、软件名称、水印或伪文字。流程含义由 README 中紧邻图片的中文图注解释。

## 2. 统一视觉系统

采用 Nature/Cell 类期刊图形摘要的扁平科研插图语言：

- 背景为纯白或接近纯白，不使用深色底；
- 主体使用干净的二维矢量感轮廓，允许轻微明暗层次，但不使用影视化三维体积光；
- 主色为低饱和学术蓝和蓝绿色，深灰蓝用于轮廓与连接线；
- 少量低饱和橙色只用于独立湿实验验证入口，以建立证据边界；
- 线条粗细、分子球棍比例、蛋白轮廓抽象程度和箭头样式在两张图中保持一致；
- 保留充足留白，避免粒子雨、霓虹光晕、镜头炫光、金属材质、黑色宇宙背景和装饰性数据界面。

建议色彩锚点为学术蓝 `#3B6F9C`、蓝绿色 `#4C9A91`、深灰蓝 `#334E5C`、浅蓝灰 `#DCE8EC`，以及仅供实验验证使用的低饱和橙色 `#D58A4A`。图像生成允许围绕这些色值作小幅自然变化。

## 3. 项目图标

### 3.1 构图

图标保持正方形画幅、白色背景和居中构图。主体由三个层次组成：

1. 一个开放、非封闭的蛋白结合口袋轮廓；
2. 一个正在进入或贴合口袋的小分子球棍模型；
3. 少量节点连接和一条细弧形轨迹，分别表示 AI 精评和分子动力学复核。

蛋白口袋使用蓝绿色面与深灰蓝细轮廓，小分子使用学术蓝，并以一个克制的暖色原子作为视觉焦点。节点和轨迹只能作为辅助，不得形成靶心、奖章、对勾或“已确认”图形。

### 3.2 可用性

- 最终 PNG 不低于 1024 × 1024；
- 四周保留约 12% 安全边距；
- 缩小至 64–128 px 时仍能辨认“小分子进入蛋白口袋”的主体关系；
- 不使用细密背景纹理或依赖大尺寸才能看清的装饰。

## 4. 流程示意图

### 4.1 信息结构

流程图采用宽幅白底画布，从左向右形成连续且逐步收敛的六段结构：

1. 一至五个形态不同的查询小分子；
2. 由多种蛋白轮廓和口袋组成的人源蛋白组结构库；
3. 多个蛋白–配体姿势表示背景校准的批量对接；
4. 简洁的节点网络及少量复合物表示 AI 复合物精评；
5. 带水分子点和细轨迹的复合物表示分子动力学复核；
6. 少量分层候选输出，以及与计算输出保持明显间隔的独立湿实验验证入口。

阶段间使用统一的细实线箭头或渐细连接线。候选数量与视觉密度从左至右递减，形成无需文字也能识别的筛选漏斗。不得使用封闭卡片、软件界面、坐标轴、装饰性网格或伪数据标签。

### 4.2 实验验证边界

计算阶段统一使用蓝、蓝绿和灰蓝色。最右侧实验器皿或微孔板可使用低饱和橙色，但必须满足以下条件：

- 与最终计算候选之间保留明显留白；
- 仅以细橙色虚线连接，表示后续转交而非同一计算阶段；
- 不出现对勾、靶心、阳性信号爆发或其他确定性成功符号；
- 图注继续明确计算排序不等同于实验确认。

### 4.3 可用性

- 最终 PNG 宽度不低于 1536 px，宽高比约 2:1；
- 在 GitHub README 页面宽度下可辨认六段结构和候选收敛关系；
- 箭头方向全部从左向右，不出现反向箭头；
- 不依赖颜色作为唯一信息来源，实验阶段同时通过间隔和虚线与计算阶段区分。

验收条件：

- 两张图均为白底、扁平科研图形摘要风格，并形成统一视觉系统；
- 不含任何文字、数字、伪文字、水印或品牌标识；
- 不含霓虹光效、深色科幻背景、影视化材质或商业宣传式符号；
- 分子、蛋白口袋、AI 节点、MD 轨迹和实验入口的语义可辨；
- 流程方向正确，输入、候选收敛和实验验证边界清楚；
- PNG 可正常解码，尺寸和比例满足约束；

- 完整测试、Ruff、mypy 和 `git diff --check` 继续通过。
