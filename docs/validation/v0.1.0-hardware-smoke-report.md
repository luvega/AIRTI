## 2. 实测结果

### 2.1 QuickVina2

使用合成 PDBQT 受体和单碳配体执行固定种子 29、`exhaustiveness=1` 的最小搜索。程序完成网格解析、全局搜索、结果精修和 PDBQT 写出，返回 1 个构象；日志中的示例亲和力为 `-0.3 kcal/mol`，搜索耗时约 0.2 s。

该夹具仅检验二进制执行、输入解析、搜索和输出链路，不具有生物学基准意义。

### 2.2 GROMACS

使用 2 nm 立方 TIP3P 水盒，共 663 个原子，执行 1000 步、2 ps 的最小 MD。日志显示：

- 检测并选择 1 张 GPU；
- 短程非键相互作用在 GPU 上执行；
- 坐标更新与约束在 GPU 上执行；
- 任务正常写出最终坐标和 checkpoint；
- 本次脚本化实测性能为 1288.107 ns/day。

该性能来自极小水盒，只用于证明 GPU kernel 链路，不可外推至蛋白–配体 100 ns 生产体系。

### 2.3 Boltz-2

使用泛素短蛋白序列与咖啡因 SMILES，固定种子 29，在单序列、低采样 smoke 参数下同时运行结构与亲和力头。日志显示 `GPU available: True (cuda), used: True`，设备为 NVIDIA GeForce RTX 4090，两个阶段的失败样本数均为 0。输出包括 mmCIF、置信度 JSON、亲和力 JSON 和 PAE/PDE 数组。

本次低采样输出的 `confidence_score=0.4713`、`ligand_iptm=0.3449`。这些数值只用于核验输出 schema，不进入模型性能或靶点排序结论。生产运行禁止用 `msa: empty` 替代按版本缓存的 MSA，并采用冻结的完整采样参数和三随机种子共识。

## 3. 可重复执行

```bash
./scripts/run_hardware_smoke.sh
```

脚本拒绝覆盖既有结果目录，执行三条真实计算路径，核对关键日志与输出文件，校验两个 Boltz 检查点哈希，并为本次运行生成 `artifacts.sha256`。

本次通过记录位于 `/data/airti-target-fishing/runs/IMAGE-SMOKE-20260813-DC13F27`。运行目录同时保存 `image-digest.txt` 与 `image-revision.txt`，后者与镜像 OCI revision 标签一致。镜像内 `/tmp/airti-cache/{numba,matplotlib,xdg,triton}` 均采用 `1777` 权限，并已使用 `--user 1000:1000` 验证写入，以适配调度系统注入的非 root UID。
