# AIRTI v0.1.0 十查询编排 smoke 验证报告

**验证日期**：2026-08-13

**验证范围**：Nextflow DSL2 模拟工具链

**结论**：10 个查询按两个 5 分子批次完成六阶段编排，随后使用 `-resume` 恢复时 12 个进程均命中缓存。该结果证明批次上限、查询身份传递、交付清单与恢复机制符合当前编排合同，但不包含真实对接、Boltz-2、MD 或全蛋白组检索结果。

## 1. 输入与批次

批次 A 包含 caffeine、aspirin、acetaminophen、salicylic acid 和 nicotinamide；批次 B 包含 benzamide、acetophenone、anisole、phenetole 和 indole。每个条目具有独立的 smoke 标识，两个批次均不超过生产服务规定的 5 分子上限。

输入清单固定在：

- `data/benchmark/smoke_v1_batch_a.smi`；
- `data/benchmark/smoke_v1_batch_b.smi`。

## 2. 验证结果

| 检查项 | 结果 |
|---|---|
| 查询数与唯一性 | 10/10，标识无重复 |
| 批次数与最大批量 | 2 个批次；每批 5 个 |
| 首次运行 | 每批 6/6 进程完成 |
| 恢复运行 | 每批 6/6 进程为 `CACHED`，未提交重算 |
| 模拟技术成功率 | 100% |
| 报告 SHA-256 | 2/2 与交付清单一致 |
| 指标工件追溯标记 | 通过 |
| unsupported 靶点缺失值语义 | 通过，不生成伪数值分数 |
| 工件清单 | 已生成 `artifacts.sha256` |

自动生成的顶层摘要将验证范围写为 `orchestration_mock_only`。测试使用一个 ready 靶点和一个 unsupported 靶点，固定模拟分数只用于检查字段传递，不参与任何算法或生物学结论。

## 3. 可重复执行

```bash
./scripts/run_orchestration_smoke.sh
```

脚本默认创建带时间戳的新目录，并拒绝覆盖既有运行；也可将目标目录作为第一个参数传入。Nextflow 固定为 24.10.4，离线使用本地已安装框架，首次执行与恢复执行分别保留日志、trace、timeline 和 HTML 报告。

## 4. 尚未满足的真实实测门槛

生产 Nextflow 当前依赖 `prepare-ligands`、`screen`、`refine-boltz`、`run-md` 和 `render-report` 五个 AIRTI CLI 命令；这些命令尚未全部接入已实现的 Python 适配器。完成桥接后，还需依次形成以下证据：

1. 冻结版本的全人 canonical 蛋白结构与口袋清单；
2. 每口袋背景探针对接校准分布及异常统计；
3. 两个不超过 5 分子的真实检索批次；
4. Boltz-2 三种子精评与 Top 10 蛋白–配体 100 ns MD；
5. 盲测检索率、校准、失败恢复和发布门槛记录。

在上述证据完成前，本 smoke 不计入“10 例真实端到端检索通过”，也不触发 v0.1.0 候选版发布。
