# ff19SB/GAFF2 provenance and validation gate

AIRTI does **not** vendor a hand-converted static GROMACS force-field tree in
this directory. Production systems are parameterized from the AmberTools files
installed in the version-locked simulation image:

- protein: `leaprc.protein.ff19SB`;
- ligand: `leaprc.gaff2`, AM1-BCC charges generated by Antechamber;
- water: Amber TIP3P;
- ions: the matching AmberTools parameter set.

LEaP writes `prmtop`/`inpcrd`; ParmEd converts that exact system to GROMACS
topology and coordinates. A failed Antechamber, LEaP, or ParmEd step is a hard
failure. The workflow must never substitute another force field silently.

Each production manifest records the simulation-image digest, AmberTools,
ParmEd and GROMACS versions, and SHA-256 checksums of all loaded `leaprc`,
`frcmod` and parameter files. Before an image may be released, a pinned
protein–ligand fixture must satisfy both:

1. all bonded and non-bonded single-point energy components agree between the
   Amber and GROMACS representations within 0.1 kJ mol-1 per atom; and
2. force RMS difference is at most 0.1 kJ mol-1 nm-1 after atom-order mapping.

This conversion-and-comparison gate is the source of truth for force-field
compatibility; the directory name is retained as the stable workflow asset
identifier.
